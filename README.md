# Cody 剪片模板圖鑑

讓學員直接瀏覽 12 套剪片模板的畫面示意、適用素材與可複製指令。

- 單一靜態 `index.html`，圖片、樣式與互動程式已內嵌，無外部套件依賴。
- GitHub Pages 從 `main` 分支的根目錄發布；更新 `index.html` 並推送即可更新網站。
- 頁面提供模板篩選、圖像放大、素材準備清單與指令複製。
- 示意圖是原創排版與用途圖解，非實際客戶成片。
